# Nguyên Hoang · tệp cài bản thử nghiệm

MMORPG tu tiên 3D. Trang chủ, hướng dẫn cài và tin cập nhật: https://nguyenhoang.32-236-153-164.sslip.io

Kho này chỉ chứa tệp cài. Bản mới nhất nằm ở mục [Releases](../../releases/latest):

| Máy | Tệp | Yêu cầu |
|---|---|---|
| Android | `NguyenHoang-android.apk` | Android 9 trở lên, máy 64-bit |
| macOS | `NguyenHoang-mac.zip` | macOS 12 trở lên, chip Apple hay Intel |
| Windows | `NguyenHoang-windows.zip` | Windows 10, 11 bản 64-bit |

iPhone, iPad: tham gia thử qua TestFlight, link ở trang chủ.

Bản thử nghiệm chưa ký với Apple, Microsoft, Google: lần đầu mở máy sẽ cảnh báo. Cách mở xem mục Hỏi đáp trên trang chủ.
